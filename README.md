# DS340WProject
DS340W Fall 2026 Project

Predicting U.S. Flight Delays and Cancellations Using Statistical Modeling and Machine Learning
Grace Rovinsky, Nurnayli Qistina Mohd Harith

Abstract— Flight delays and cancellations are common problems in air travel that can affect passengers, airlines, and airport operations. This project proposes using large-scale U.S. flight data from 2019 to 2022 to develop machine learning models for predicting flight delays and cancellations. Historical flight information from multiple airlines and airports will be cleaned and analyzed to identify patterns and factors associated with these disruptions. Statistical and machine learning models will then be trained and compared using appropriate evaluation metrics. The goal of this project is to determine how accurately flight delays and cancellations can be predicted and which factors are most useful for making these predictions.
